# سناریوی ضبط دمو — حداکثر پنج دقیقه

زمان هدف: ۴ دقیقه و ۵۰ ثانیه. پیش از ضبط برنامه و دیتابیس را اجرا و seed کنید. حساب‌های نمونه باید فعال و دارای نقش اولیه باشند. سه پروفایل مرورگر جدا برای OWNER، MANAGER و MEMBER آماده کنید تا کوکی‌ها تداخل نکنند. README، نمودار معماری، قرارداد API و گزارش بررسی نهایی را باز نگه دارید؛ فایل env و مقدار secret را نشان ندهید.

برای صفحه‌بندی، از قبل حداقل ۱۳ تسک قابل‌مشاهده برای OWNER آماده کنید؛ هر صفحه ۱۲ مورد دارد. یک تسک با سازنده OWNER و مسئول MEMBER و یک تسک نامرتبط با MEMBER آماده کنید. ورود OWNER را حین ضبط انجام دهید؛ دو پروفایل دیگر می‌توانند از قبل وارد شده باشند. داده‌های دمو را دستی بسازید؛ seed فقط کاربر ایجاد می‌کند.

مقادیر رمز در README جای‌نگهدار هستند؛ از رمز توسعه‌ای تنظیم‌شده در env محلی استفاده کنید و آن را در ویدئو نشان ندهید. پس از ضبط در صورت نیاز صرفاً داده‌های دمو را پاک کنید؛ دیتابیس یا volume را reset نکنید. صفحه دوم را از قبل آماده کنید و نتیجه تست اجرا‌نشده را ادعا نکنید.
